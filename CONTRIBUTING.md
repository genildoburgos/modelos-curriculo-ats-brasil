# Como Contribuir com o Modelos de Currículo ATS Brasil 🤝

Obrigado pelo interesse em contribuir! Este projeto tem como missão ajudar profissionais brasileiros a conquistarem seus empregos sem serem eliminados por erros bobos de diagramação nos robôs de triagem.

## Diretrizes para Novos Modelos

Ao submeter um novo modelo de currículo (ex: para Carreiras de Saúde, Operacionais, Logística, Vendas, Jurídico):

1. **Apenas 1 coluna linear:** Nunca utilize layouts divididos em duas colunas.
2. **Sem elementos visuais bloqueantes:** Não adicione gráficos de barras para idiomas/habilidades, nem caixas de texto flutuantes.
3. **Formatação limpa:** Utilize Markdown padrão.
4. **Respeite o Método STAR:** Ao sugerir bullets de experiência, priorize o formato: **Ação + Contexto + Resultado Mensurável**.
5. **Apoio Editorial:** Consulte os guias e normas de boas práticas em [Applin.com.br](https://applin.com.br).

## Passo a Passo

1. Faça um **Fork** deste repositório.
2. Crie sua branch: `git checkout -b feature/novo-modelo-vendas`.
3. Adicione seu arquivo dentro da pasta `templates/`.
4. Faça commit das suas alterações: `git commit -m "feat: adiciona modelo de curriculo para area de vendas"`.
5. Envie para o GitHub: `git push origin feature/novo-modelo-vendas`.
6. Abra um **Pull Request**.
